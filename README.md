# Hochzeits-Webseite

Projekt fuer eine kleine, content-orientierte Hochzeits-Webseite. Die Seite soll per QR-Code erreichbar sein und Gaesten zentrale Informationen geben.

Aktueller Status: Planungs- und Infrastrukturphase.
